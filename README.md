# CircuPilot

**AI-Powered Circuit Design and Simulation**

[CircuPilot](https://circupilot.com) is an AI-powered platform for designing, editing, and simulating electronic circuits.

Users can generate circuits from natural-language descriptions or circuit images, refine designs with AI, and run SPICE simulations. The platform also supports embedded development and simulation workflows for Arduino and AVR microcontrollers.

🌐 **Live Platform:** https://circupilot.com

## About This Repository

This public repository contains an **early research prototype** developed during the initial stages of CircuPilot. It demonstrates the project's foundational approach to AI-assisted circuit design, using a Circuit Intermediate Representation (CIR) to connect circuit generation, schematic visualization, and SPICE netlist generation.

The live platform has evolved significantly beyond this prototype and is developed in a separate private repository. **Not all features available on the website are implemented in this public repository.**

## Technologies

- **Frontend:** React
- **Backend:** FastAPI
- **Circuit Representation:** Circuit Intermediate Representation (CIR)
- **Simulation:** PySpice / ngspice
- **Deployment:** Docker
